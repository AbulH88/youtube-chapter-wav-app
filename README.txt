YOUTUBE CHAPTER WAV APP

1. Double-click "Launch YouTube Chapter WAV App.bat".
2. Paste a YouTube video link.
3. Choose an output folder.
4. Click "Start conversion".

The app creates a folder named after the video. Its WAV subfolder contains
numbered, lossless 16-bit PCM WAV files—one per YouTube chapter.

Downloaded audio and other temporary media are removed automatically. Videos
without chapter markers are saved as one WAV file.

Keep this entire app folder together. The tools folder and SharedLog.ps1 are required.
